# 新原寸山積予定Ver03.xlsm 仕様書

> **ファイル種別**: .xlsm（マクロ付き）
> **用途**: 原寸（フルスケール）工程の山積み（負荷積み上げ）スケジュール管理。工事ごとの作業時間を日次カレンダーに展開し、全体の負荷推移を可視化する
> **VBA プロジェクト**: Module1, Module2, ThisWorkbook, Sheet1 に計 738行のマクロコード
> **外部連携ファイル**: `工事実績(集計マクロ)(Ver4(現行Ver)).xls`, `原寸実績.xls`

---

## 1. ファイル構成

```
新原寸山積予定Ver03.xlsm
├── Sheet1   (801行 x 7,380列) — メインスケジュール・山積みデータ
│   ├── 行1-29: 設定・制御エリア
│   ├── 行30: ヘッダー行
│   ├── 行31: 集計行（ペースライン等）
│   └── 行32-801: 工事データ（1行 = 1工事）
├── Sheet2   (空 / 未使用)
└── Sheet3   (作業用バッファ — マクロによる一時データ格納)
```

## 3. 期間（1-4）の概念

各工事は最大4つの期間に分割して工程を管理する:

```
【工事の時間配分】
  作業予定時間 = 200H
    ├── 期間1: 比率 40% = 80H  着手 7/1 → 完了 7/20
    ├── 期間2: 比率 30% = 60H  着手 8/1 → 完了 8/15
    ├── 期間3: 比率 20% = 40H  着手 9/1 → 完了 9/10
    └── 期間4: 比率 10% = 20H  着手 10/1 → 完了 10/5
```

展開マクロにより、各期間の着手日〜完了日にわたって「1日あたりの時間」を均等配分する。

## 5. VBA モジュール仕様

### 5.1 ThisWorkbook

#### `Workbook_Open()`

ブック起動時にイベントを有効化し再計算を実行。

### 5.2 Sheet1

#### `Worksheet_SelectionChange(Target)`

工程セル（列16以降 × 行32以降）選択時に `セル日付_所得` を呼び出し、制御エリアに着手/完了/予定時間/比率を自動セット。

#### `Worksheet_Change(Target)`

グラフ起点日（C2）が変更されたとき `名前定義` を呼び出してグラフ範囲を更新。

### 5.3 Module2

#### `日報反映()`

**処理概要**: 外部の `工事実績(集計マクロ)(Ver4(現行Ver)).xls` から、選択中工事の日報時間データを取得し、Sheet1 のカレンダー上の対応日付列に反映する。

**処理フロー**:
1. `工事実績(集計マクロ).xls` を開く（パス: `I:\マイドライブ\仕事用\管理\`）
2. 選択中工事の工事番号でフィルタリング
3. フィルタ結果を Sheet3（バッファ）にコピー
4. Sheet3 の各行をループ:
   - 日報日付 → カレンダー列番号を算出
   - 工事時数 → 該当行×該当列に書き込み
5. Sheet3 をクリア、ブックを保存

#### `展開()`

**処理概要**: 期間1-4 の着手日・完了日・比率に基づき、1日あたりの作業時間をカレンダー上に均等配分する。

**処理フロー**:
1. 入力バリデーション（期間/着手/完了の入力漏れチェック、過去日付チェック）
2. 期間1から順にループ（最大4回）:
   - 着手日のカレンダー列を特定
   - 作業日数 + 休日日数を算出
   - 休日以外のセルに `1日あたりの時間` を書き込み
   - 未工程フラグがある場合はマイナス値で書き込み
3. ブックを保存

#### `工事一覧更新()`

**処理概要**: 外部の `原寸実績.xls` から工事マスタを同期。新規工事の追加・既存工事の属性更新を行う。

**処理フロー**:
1. `原寸実績.xls` を開く（パス: `I:\共有ドライブ\原寸G\`）
2. 重量 0.002t 以上でフィルタ
3. Sheet3 にコピー、不要列を削除して整理
4. Sheet3 の各行をループ:
   - 工番で Sheet1 を検索
   - 既存 → 客先/工事名/品種/納期/重量/受領日/作業時間/進捗率/担当を更新
   - 未存在 → ユーザーに山積み要否を確認（InputBox）→ 要なら Sheet1 に行追加
5. 原寸実績.xls に山積み判定（○/x）を反映・保存
6. Sheet3 をクリア

### 5.4 Module1

#### `セル日付_所得(Target)`

Sheet1 の SelectionChange イベントから呼ばれ、選択されたセルの位置から期間番号を判定し、制御エリア（着手/完了/予定時間/比率/ActiveRow）を更新する。

#### `名前定義()`

既存の名前定義をすべて削除し、グラフ用の名前定義（グラフ期間, 伸縮受領, 全体定時間ペースライン 等）を I10-I25 セルの値に基づいて再設定する。

```
【工事一覧更新フロー】
  原寸実績.xls（共有ドライブ）
       ↓ 工事一覧更新マクロ

  ユーザーが期間1-4の比率・着手日・完了日を入力
       ↓ 展開マクロ
  着手日〜完了日の各カレンダー列に均等配分
       ↓
  山積みグラフに自動反映（名前定義範囲のSUM集計）
```

## 8. 山積みグラフの仕組み

カレンダー行の先頭行（行9〜行29付近）に、カテゴリ別の日次合計行がある:

```
行9:  伸縮（受領済み）の日次合計
行10: 伸縮外（受領済み）の日次合計
行11: 伸縮（受領済み・未工程）
行12: 伸縮外（受領済み・未工程）
行13: 伸縮（未受領）
行14: 伸縮外（未受領）
行15: 全体定時間ペースライン（累積）
行18: 全体2H残業ペースライン
行19: 全体4H残業ペースライン
行20-24: 伸縮カテゴリのペースライン
行25-29: 橋体カテゴリのペースライン
```

グラフはこれらの行を名前定義で参照し、負荷の山積み状況とペースライン（消化能力の上限）を対比する。

## 9. システム移行時のポイント

- **7,380列の日次カレンダー → DB の日付テーブルに移行**: 各工事×日付の組み合わせで `allocated_hours` を管理
- **期間1-4 の概念**: 1工事に最大4つの作業期間（フェーズ）を割り当て可能
- **未工程フラグ**: 工程未確定の時間は負の値として積み上げ（グラフ上で色分け可能）
- **外部ファイル連携 → API化**: 日報実績の取り込みと工事マスタ同期をシステム内で完結
- **ペースライン**: 定時間/2H残業/4H残業の3レベルのキャパシティライン → 設定マスタで管理
- **カテゴリ分類**: 伸縮 / 伸縮外 / 橋体の3カテゴリで負荷を集計
