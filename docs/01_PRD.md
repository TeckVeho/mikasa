# 01 プロダクト要件定義書（PRD）

## 1. プロダクト概要


| 項目     | 内容                                     |
| ------ | -------------------------------------- |
| プロダクト名 | LogiVoice（仮称）                          |
| カテゴリ   | 電話自動対応 AI SaaS                         |
| ターゲット  | 中小〜中堅の物流会社（配送・宅配・3PL）                  |
| 提供形態   | クラウド型 SaaS（MVP は単一テナント、フェーズ3でマルチテナント化） |


## 2. 解決する課題

### ユーザーの課題

- 再配達・配送確認の電話が1日数百件以上あり、オペレーターを圧迫している
- 夜間・休日の着信に対応できず、顧客満足度が低下している
- ドライバーへの連絡調整（ルート変更・集荷依頼）に時間がかかる
- 2024年問題以降、物流業界の人手不足が深刻で採用コストが高騰している

### 解決策

AI ボイスボットが電話を24時間自動対応し、再配達受付・配送状況案内・集荷依頼を自動処理する。
管理者はノーコードのシナリオエディタでフローを自由に編集できる。

## 3. ユーザーストーリー

### 管理者（コールセンター責任者）

- シナリオを自分で作成・編集して、翌日から自動対応を開始したい
- 受電件数・完結率・対応時間をダッシュボードで確認したい
- 有人対応が必要な件数を最小化したい
- 料金が利用量に応じて変動するので、コストを予測したい

### オペレーター

- ボイスボットが受け付けた内容をテキストで確認・修正したい
- 必要な案件だけに折り返し電話できるようにしたい
- 通話音声を後から聞き直したい

### エンドユーザー（荷受人・荷主）

- 24時間いつでも電話して再配達を依頼したい
- 短時間で用件を完結させたい（長いメニューを聞かされたくない）
- 住所や日時を正確に認識してもらいたい

## 4. 機能要件

### Must（MVP必須）

- 着信の自動応答（24時間）
- 音声認識によるヒアリング（氏名・住所・日時・用件）
- シナリオフローに沿った対話進行
- 有人オペレーターへの転送
- 通話ログの保存・テキスト化
- 管理画面ログイン（メール+パスワード）
- シナリオのノーコード作成・編集
- 電話番号の取得・管理・シナリオ紐づけ

### Should（フェーズ2）

- 通話後の自動要約（生成AI）
- SMS送信（通話後の確認メッセージ）
- ダッシュボード KPI グラフ
- 住所認識の高精度化（ZENRIN連携）
- 折り返し受付シナリオ

### Could（フェーズ3以降）

- アウトバウンド発信（配送遅延通知）
- TMS/WMS API連携
- マルチテナント・課金管理
- 多言語対応

## 5. 非機能要件


| 項目     | 要件                        |
| ------ | ------------------------- |
| 応答遅延   | 発話認識から返答音声まで 2秒以内         |
| 可用性    | 99.5%以上（月間ダウンタイム 3.6時間以内） |
| 同時通話数  | 最大50通話（中規模SaaS想定）         |
| データ保持  | 通話ログ・録音を90日間保存            |
| セキュリティ | HTTPS必須、JWT認証、テナント間データ分離  |
| 個人情報   | 通話データの取り扱いポリシーを管理画面に明示    |


## 6. スコープ外（作らないもの）

- 独自の音声認識エンジン（AmiVoice APIを利用）
- 独自のLLM（OpenAI APIを利用）
- ビデオ通話・チャット対応
- モバイルアプリ（管理画面はWebのみ）
- 紙帳票・FAX対応
