# 05 UI/UX仕様書

## 1. 設計原則


| 原則            | 内容                      |
| ------------- | ----------------------- |
| 非エンジニアでも操作できる | IT担当者不在でも現場担当者が管理できるレベル |
| 状態を常に明示する     | ローディング・エラー・空状態を必ず設計する   |
| 破壊的操作には確認を挟む  | 削除・公開停止は必ず確認ダイアログを表示    |
| モバイルは参照のみ     | PC操作を主とし、スマホはログ確認程度     |
| フィードバックを即時に返す | ボタン押下後1秒以内に何らかの状態変化を表示  |

### /login — ログイン画面

**レイアウト:** 中央寄せ、カード型（幅400px、縦中央配置）、背景は `--color-bg`

**要素（上から順）:**

1. ロゴ（60px height、中央）
2. 見出し「ログイン」（2xl, bold）
3. メールアドレス入力フィールド（ラベル: 「メールアドレス」）
4. パスワード入力フィールド（ラベル: 「パスワード」、右端に表示/非表示トグルアイコン）
5. 「ログイン」ボタン（full-width、primary、height 44px）
6. 「パスワードを忘れた方はこちら」テキストリンク（中央）

**状態:**

- **初期:** 全フィールド空、ボタン有効
- **送信中:** ボタンをローディングスピナーに変更、フォーム非活性
- **エラー:** フィールド上部に赤いアラートバー「メールアドレスまたはパスワードが正しくありません」
- **バリデーションエラー:** 各フィールド下に赤いテキスト（例: 「メールアドレスを入力してください」）

### /dashboard — ダッシュボード

**レイアウト:**

```
[ページヘッダー: "ダッシュボード" + 期間フィルタ]
[KPIカード行（4列）]
[グラフ行（2列）]
```

**KPIカード（4枚）:**


| カード    | 主要数値            | サブテキスト                   |
| ------ | --------------- | ------------------------ |
| 今月の受電数 | 数値（3xl, bold）   | 先月比 +12% ↑（緑）or -5% ↓（赤） |
| 自動完結率  | XX%（3xl, bold）  | 目標70%に対してXX%             |
| 平均通話時間 | m:ss（3xl, bold） | 先月比 ±XX秒                 |
| 有人転送件数 | 数値（3xl, bold）   | 全体の XX%                  |


**グラフエリア（2列）:**

- 左: 受電数の日別推移（折れ線グラフ、過去30日）
- 右: 時間帯別受電分布（棒グラフ、0〜23時）

**期間フィルタ（ヘッダー右）:** 今日 / 今週 / 今月 / カスタム（日付範囲ピッカー）

**空状態:**

> 「まだ通話データがありません。」
> 「電話番号を設定してシナリオを公開してみましょう。」
> → [電話番号を追加する] ボタン

**ローディング状態:** KPIカードとグラフをスケルトンUIで表示

### /calls/[id] — 通話ログ詳細

**レイアウト:** 2カラム（PC: 左7 / 右5、タブレット: 縦積み）

**左エリア: 音声プレイヤー + 文字起こし**

音声プレイヤー:

- 再生/停止ボタン（44px、視認性高く）
- シークバー
- 再生速度: 1x / 1.5x / 2x
- 音声ファイルがない場合: 「録音データなし」グレーテキスト

文字起こしエリア（スクロール可能）:

- システム発話: グレー背景、左寄せ
- ユーザー発話: 白背景、左寄せ
- 各発話に開始時刻を表示（クリックで音声プレイヤーがシーク）

- ヘッダー「AI要約」+ 展開/折りたたみボタン
- 要約テキスト表示
- 要約生成中: スピナー + 「要約を生成中...」

## 6. 共通コンポーネント

### ナビゲーション（左サイドバー）

- 幅: 240px（タブレットでは折りたたみ可能）
- 背景: `--color-surface` + 右border
- アイテム: アイコン（24px）＋ラベル、高さ44px
- 現在地: `--color-primary` の左ボーダー（4px）＋薄い青背景
- 最下部: ユーザーアバター＋名前＋ログアウトリンク

### トースト通知

- 表示位置: 画面右上（margin 16px）
- 最大同時表示: 3件（古いものから消える）
- 種別: success（緑）/ error（赤）/ info（青）
- 自動消去: 5秒後（エラーは8秒）
- 手動消去: × ボタン

### 削除確認ダイアログ

```
「[対象名] を削除しますか？」
この操作は元に戻せません。

[キャンセル]  [削除する（赤ボタン）]
```

### 空状態コンポーネント

- 軽量SVGイラスト（100px程度）
- 見出し（何もない状態の説明）
- サブテキスト（次のアクションの誘導）
- CTAボタン（任意）

### ローディング状態

- ページ全体: 中央に回転スピナー
- テーブル・カード: スケルトンUI（幅・高さは実際と同じ）
- ボタン: テキストをスピナーに置き換え＋非活性化

---

## 7. レスポンシブ方針


| ブレークポイント           | 対応                                  |
| ------------------ | ----------------------------------- |
| PC (1280px 以上)     | フル機能・2カラムレイアウト                      |
| タブレット (768〜1279px) | サイドバーをハンバーガーメニューに、1カラムに変更           |
| モバイル (768px 未満)    | 通話ログの確認・ステータス確認のみ。シナリオエディタ非対応（警告表示） |


---

## 8. アクセシビリティ

- フォーカスリングを常に表示（`outline: none` 禁止）
- すべての操作ボタンに `aria-label` を付与
- エラーメッセージを `role="alert"` で実装
- カラーのみで状態を伝えない（アイコン・テキストを併用）
- コントラスト比: テキストは 4.5:1 以上
- キーボードのみで全操作可能にする
