# 過去12年工事記録平均時間 算出.xls 仕様書

> **ファイル種別**: .xls（Excel 97-2003）
> **用途**: 過去12年間の橋梁製作工事の実績データを蓄積し、品種別の平均製作時間を算出するためのマスタデータ
> **外部連携ファイル**: なし（単体利用）

---

## 1. ファイル構成

```
過去12年工事記録平均時間 算出.xls
├── I型 集計        (2,416行 x 26列) — I型桁の工事実績データ
├── 箱型 集計       (4,952行 x 67列) — 箱型桁の工事実績データ（追加属性あり）
├── 座繰り 集計     (1,967行 x 26列) — 座繰り桁の工事実績データ
├── SEF             (261行 x 43列)   — SEF（鉄骨ファブ）の工事実績データ
└── 集計時追加項目   (46行 x 5列)    — 箱型集計用の補助パラメータ定義
```

---

## 2. シート詳細

### 2.1 I型 集計

**目的**: I型桁（鋼製橋梁）の工事単位の製作実績を蓄積し、過去平均時間を算出する。

#### レイアウト構造

| セル範囲 | 内容 |
|---------|------|
| T1 | タイトル「過去データからの平均時間」 |
| A3〜 | 工事データ開始行 |

#### データ構造（1工事 = 複数行ブロック）

各工事は以下の行構造で格納される:

| 列 | ヘッダー | 内容 | 型 |
|----|---------|------|-----|
| A | — | 工事番号 + 発注元 | テキスト |
| B | — | 橋梁名 + 日付 | テキスト |
| C | 製作班 | 担当班名（阪上班 等） | テキスト |
| D | 過去平均 | 行ラベル（「予定時間」「実数時間」等） | テキスト |
| E | 製造予定 | 製造予定時間 | 数値（時間） |
| F | 営業予定 | 営業予定時間 | 数値（時間） |
| G | 工事重量 | 重量（トン） | 数値 |
| H | 組立前 | 組立前工程の時間 | 数値（時間） |
| I | 組立 | 組立工程の時間 | 数値（時間） |
| J | 溶接 | 溶接工程の時間 | 数値（時間） |
| K | 歪取り | 歪取り工程の時間 | 数値（時間） |
| L | 塗装 | 塗装工程の時間 | 数値（時間） |
| M | 仕上げ | 仕上げ工程の時間 | 数値（時間） |
| N | 工事時間 | 合計工事時間 | 数値（時間） |
| P | 部材長さ | メートル | 数値 |
| Q | M毎重量 | メートルあたり重量 | 数値 |
| W | 差 | 予定と実績の差 | 数値 |

#### 工事データの行構造

```
行1: 工事番号・発注元 | 橋梁名・日付 | 製作班 | "予定時間" | 製造予定 | ... | 工事時間
行2:                 |             |       | "実数時間" | 実績値   | ... | 合計実績
行3:                 |             |       | "工場平均" | 平均値   | ... | 平均合計
（空行で次の工事へ）
```

### 2.2 箱型 集計

**目的**: 箱型桁の工事実績データ。I型と同じ基本構造 + 追加属性。

#### 追加カラム（箱型固有）

| 列 | ヘッダー | 内容 |
|----|---------|------|
| O | 件数 | SET件数 |
| Y | t/製作時間 | トンあたり製作時間 |
| Z | M/製作時間 | メートルあたり製作時間 |
| AC | SET数 | 基数 |
| AD | 櫛角度 | 斜角（度数をコード化: 90°=0, 80-90°=1, ...） |
| AE | ジョイント数 | ジョイントの総合計数 |
| AF | 歩道・中地覆 | 地覆有無コード（0=なし, 1=両側地覆, 1+α=歩道等） |
| AG | 塗装系数 | 塗装の系数 |
| AH | サス樋 | サスペンション樋の有無 |
| AI | 他 | その他の属性 |
| AA | 相関係数 | 統計的相関 |

### 2.3 座繰り 集計

**目的**: 座繰り（カウンターボア）型の工事実績データ。I型と同じ基本構造。

### 2.4 SEF

**目的**: SEF（Steel Erection Fabrication）の実績。基本構造は同一だが、列 X以降に個別の橋梁名ごとの横並びデータあり。

### 2.5 集計時追加項目

**目的**: 箱型集計の追加属性のコード定義表。

| 項番 | 項目名 | 定義 |
|------|--------|------|
| 1 | SET数 | ジョイント毎ではなく基数 |
| 2 | 斜角（櫛角度） | 90°=0, 80-90°=1, 70-80°=2, 60-70°=3, 50-60°=4 |
| 3 | ジョイント数 | ジョイントの総合計数 |
| 4 | 歩道・中地覆 | なし=0, 両側地覆=1, 歩道等は+1ずつ加算 |
| 5 | 塗装系の数 | 塗装系統の数 |
| 6 | サス樋 | なし=0, あり=1 |
| 7 | 他 | 上記以外の特殊工事 |

## 3. データフロー

```
【工事完了時】
  工事の実績データ（工程別時間・重量・部材長さ等）
       ↓ 手動入力
  品種別シート（I型/箱型/座繰り/SEF）に行追加
       ↓
  過去平均の参照データとして蓄積
       ↓
  新規工事の予定時間見積りに利用
  → 泉北工程.xlsx の「過去平均」列
  → 新原寸山積予定.xlsm の「作業予定時間」の算出根拠
```

---

## 4. システム移行時のポイント

- **品種マスタ**: I型 / 箱型 / 座繰り / SEF の4品種分類
- **工程マスタ**: 組立前 / 組立 / 溶接 / 歪取り / 塗装 / 仕上げ の6工程
- **追加属性（箱型）**: SET数・斜角・ジョイント数・地覆有無・塗装系数・サス樋は DB カラムまたは属性テーブルで管理
- **データ量**: 約12年分、全シート合計 約50,000セルの実績データ
- **統計計算**: 品種別・工程別の平均時間、トン/メートルあたりの製作時間
