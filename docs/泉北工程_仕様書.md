# 泉北工程.xlsx 仕様書

> **ファイル種別**: .xlsx
> **用途**: 泉北工場における製作班ごとの工程管理・進捗追跡・負荷可視化。工事単位で工程別（組立前～仕上げ）の目標・実績・日次スケジュールを管理する
> **外部連携ファイル**: なし（単体利用、ただし過去平均時間は別ファイルから参照している可能性あり）

---

## 1. ファイル構成

```
泉北工程.xlsx
├── 配信用グラフ      (35行 x 17列)    — 社内配信用の負荷グラフ（データは他シート参照）
├── 表               (29行 x 23列)    — 全班統合サマリ（工事別KPI一覧）
├── モデル            (152行 x 179列)  — テンプレート/計算モデル
├── 実績と3ヵ月予報   (176行 x 1,115列) — 月次の実績と将来予測
├── 製作班未定        (550行 x 1,222列) — 班未割当ての工事スケジュール
├── 中野班           (253行 x 1,205列) — 中野班の工事スケジュール
├── 道姓班           (235行 x 1,205列) — 道姓班の工事スケジュール
└── 阪上班           (315行 x 1,205列) — 阪上班の工事スケジュール
```

## 2. シート詳細

### 2.1 表（統合サマリ）

**目的**: 全製作班の工事を横断的に一覧化し、目標 vs 実績の差異・進捗率・工程別実績を俯瞰する。

#### レイアウト構造

| 列 | ヘッダー | 入力/自動 | 内容 |
|----|---------|----------|------|
| A | — | — | 班識別子（「道」「中」「阪」等） |
| B | 工番番号 | 手入力 | 6桁の工番 |
| C | 工事名,納期 | 自動 | 班シートから INDEX/MATCH で取得 |
| D | 目標時間 | 自動 | 班シートから取得 |
| E | 全体実数 | 自動 | O〜T列（工程別実績）の合計 |
| F | 差 | 自動 | 目標時間 - 全体実数 |
| G | W割合 | 手入力 | 溶接の比率（%） |
| H | 進捗% | 自動 | 班シートから取得 |
| I | 鍛冶目標 | 自動 | 目標時間 - 溶接目標 |
| J | 鍛冶実数 | 自動 | 全体実数 - 溶接実数 |
| K | 差 | 自動 | 鍛冶目標 - 鍛冶実数 |
| L | 溶接目標 | 自動 | 目標時間 × W割合 |
| M | 溶接実数 | 自動 | =Q列（溶接工程の実績） |
| N | 差 | 自動 | 溶接目標 - 溶接実数 |
| O | 組前 | 自動 | 組立前の実績時間 |
| P | 組立 | 自動 | 組立の実績時間 |
| Q | 溶接 | 自動 | 溶接の実績時間 |
| R | 歪取り | 自動 | 歪取りの実績時間 |
| S | 塗装 | 自動 | 塗装の実績時間 |
| T | 仕上げ | 自動 | 仕上げの実績時間 |
| U | 過去平均時間 | 自動 | 班シートから取得 |
| V | 製作完了予想時間 | 自動 | 全体実数 ÷ 進捗% × 100 |
| W | 予想時間と目標時間との差 | 自動 | 目標時間 - 予想完了時間 |

#### 主要な数式

```
C5 = INDEX(道姓班!$C$5:$C$194, MATCH(表!$B5, 道姓班!$B$5:$B$194, 0))
D5 = INDEX(道姓班!$B$5:$B$194, MATCH(表!$B5, 道姓班!$B$5:$B$194, 0)+3)
E5 = SUM(O5:T5)
L5 = D5 * G5 * 0.01
V5 = SUM(E5/H5) * 100
```

### 2.2 製作班シート共通構造（中野班 / 道姓班 / 阪上班 / 製作班未定）

**目的**: 各製作班が担当する工事の詳細スケジュールと工程別進捗を管理する。

#### ヘッダーエリア（行1-3）

| セル | 内容 |
|------|------|
| H1-H3 | 「確認用」ラベル |
| I2-J2 | 米年（=アメリカ暦年）表示 |
| I3-J3 | 休会（=休日・会議）フラグ |
| T2-T3 | 年・月の起点 |

#### 列構造（行4: ヘッダー行）

| 列 | ヘッダー | 内容 |
|----|---------|------|
| B | 工事番号 | 6桁の工番 |
| C | 工事名 | 橋梁名 + 納期 |
| D | 状況 | 「出荷」「出荷待ち」「出図待ち」等 |
| E | 詳細 | 重量・SET数・補足情報 |
| F | 客先 / SET数 | 発注元企業名 |
| G | SET数 | 基数（中野班の場合） |
| I以降 | 日次カレンダー | 日付（21,22,23,...1,2,...） |

#### 工事データブロック（1工事 = 約10行）

```
行N+0: [工事番号] [工事名+納期] [状況] [詳細] [客先]  ← 工事ヘッダー
行N+1: [過去平均] [数値]  [組立前] [実績] [比率] [...] [目標]  [累積]
行N+2: [製造予定] [数値]  [組立]   [実績] [比率]
行N+3: [営業予定] [数値]  [溶接]   [実績] [比率]
行N+4:                    [歪取り] [実績] [比率]
行N+5: [実数時間]         [塗装]   [実績] [比率]
行N+6: [目標比率] [値]    [仕上げ] [実績] [比率]
行N+7: [目標比率] [値]    [小計]   [合計] [重量] [過去平均] [累積]
行N+8: [目標比率] [値]    [比率]   [H]   [面積値]
行N+9: [面積]    [値]     (日次スケジュール開始)
```

#### 工程別目標比率の計算

各工程の目標時間は、過去平均から以下の比率で配分:

```
組立前: 過去平均 × 0.249 (24.9%)
組立:   過去平均 × 0.167 (16.7%)
溶接:   過去平均 × 0.203 (20.3%)
歪取り: 過去平均 × 0.055 (5.5%)
塗装:   過去平均 × 0.073 (7.3%)
仕上げ: 過去平均 × 0.258 (25.8%)
```

#### 日次カレンダー（列I以降）

- 各工事ブロックの各工程行に日次の実績時間を入力
- 列ヘッダーは日付（日のみ表示: 21, 22, 23, ...）
- 月の区切りは行2-3の年/月で管理

#### 主要な数式（中野班の例）

```
B7 = G13                              → 過去平均 = 小計の過去平均値
D7 = SUM(I7:AIK7)                     → 組立前の実績合計（日次の横合計）
E7 = SUM(D7/G7)                       → 組立前の実績/目標比率
G7 = G13 * 0.249                       → 組立前の目標時間
H7 = SUM(I7:AMI7)                     → 組立前の累積（より広い範囲の合計）
```

### 2.3 実績と3ヵ月予報

**目的**: 月次の実績データと今後3ヶ月の予測を管理する時系列データシート。

- 行3: 月番号（1-12）が繰り返し配置
- 行2: 年の区切り（2025, 2026）
- 列間隔: 約30列/月（日次データ）

### 2.4 配信用グラフ

**目的**: 社内（部課長会議等）への配信用の負荷グラフ。データは他シートを参照。

- Q1: 日付スタンプ「2026/6/20時点」

## 3. 数式一覧（表シート）

| セル | 数式 | 説明 |
|------|------|------|
| C5 | `=INDEX(道姓班!$C$5:$C$194,MATCH(表!$B5,道姓班!$B$5:$B$194,0))` | 工事名を班シートから取得 |
| D5 | `=INDEX(道姓班!$B$5:$B$194,MATCH(表!$B5,道姓班!$B$5:$B$194,0)+3)` | 目標時間（製造予定）を取得 |
| E5 | `=SUM(O5:T5)` | 全工程の実績合計 |
| F5 | `=D5-E5` | 目標との差 |
| I5 | `=D5-L5` | 鍛冶目標 = 全体目標 - 溶接目標 |
| J5 | `=E5-M5` | 鍛冶実数 = 全体実数 - 溶接実数 |
| L5 | `=D5*G5*0.01` | 溶接目標 = 目標時間 × W割合% |
| M5 | `=Q5` | 溶接実数 = 溶接工程実績 |
| O5-T5 | `=INDEX(道姓班!$D$5:$D$194,MATCH(…)+N)` | 各工程の実績時間を班シートから取得 |
| U5 | `=INDEX(道姓班!$G$5:$G$194,MATCH(…)+7)` | 過去平均時間 |
| V5 | `=SUM(E5/H5)*100` | 予想完了時間 = 実績 ÷ 進捗率 × 100 |
| W5 | `=D5-V5` | 予想時間と目標の差 |

## 4. データフロー

```
【日次業務】
  作業者 → 班シート（中野班/道姓班/阪上班）の日次カレンダーに直接時間入力
       ↓ SUM関数で自動集計
  工程別実績合計（D列）, 目標比率（E列）が更新
       ↓ INDEX/MATCH
  表シートに自動反映 → 全工事の進捗・差異が一覧化

※ Web化後は `/teams/[id]` の班シート画面が日次入力の入口となる

【月次/部課長会議】
  表シートの KPI を確認
       ↓
  配信用グラフで負荷状況を共有
       ↓
  班未割当て工事（製作班未定シート）を班に振り分け
```

## 5. システム移行時のポイント

- **製作班マスタ**: 中野班/道姓班/阪上班 + 未割当てのチーム管理
- **6工程の比率定数**: 組立前 24.9%, 組立 16.7%, 溶接 20.3%, 歪取り 5.5%, 塗装 7.3%, 仕上げ 25.8% → 設定マスタ化
- **鍛冶/溶接の分類**: 工程を「鍛冶系（組立前+組立+歪取り+塗装+仕上げ）」と「溶接系」の2系統でも管理
- **W割合（溶接比率）の手入力**: 工事ごとに溶接の比率を人間が判断 → この入力は残す必要あり
- **状況ステータス**: 出図待ち / 出荷待ち / 出荷 等 → ステータス列挙型
- **日次カレンダー → DB**: 1,200列のカレンダーは `工事×日付×工程` の3次元テーブルに正規化
- **INDEX/MATCH の連鎖 → JOIN クエリ**: 班シート → 表シートの集計はSQL/API で自動化
