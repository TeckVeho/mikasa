# ミカサ金属 負荷計算システム — 要件サマリ

> **クライアント**: ミカサ金属株式会社（鋼橋梁製造業）
> **対象業務**: 原寸工程の負荷計算（山積みスケジュール管理）
> **現行システム**: Excel 3ファイル + VBAマクロ + 共有ドライブ連携
> **移行先**: Web システム（LogiVoice の認証基盤 + UIシェルを流用）

---

## 1. 業務概要

ミカサ金属の泉北工場では、鋼橋梁の製作工程を管理している。
工事ごとに **6つの工程**（組立前→組立→溶接→歪取り→塗装→仕上げ）を経て完成し、
各工程にかかる **作業時間を日次で計画・実績管理** するのが負荷計算業務の中核。

### 現行の Excel ワークフロー

```
原寸実績.xls（共有ドライブ）       過去12年工事記録平均時間.xls
  │ 工事マスタ同期                    │ 過去平均参照
  ↓                                 ↓
新原寸山積予定.xlsm  ←──── 過去平均で予定時間を設定
  │ 日報実績の反映                    
  │ 工程展開（期間1-4）               
  ↓                                 
山積みグラフ（伸縮/橋体/ペースライン）
  ↓                                 
泉北工程.xlsx  ←── 班別の日次実績入力・進捗追跡
  ↓
配信用グラフ → 部課長会議
```

## 2. 主要エンティティ

### 2.1 マスタデータ

| エンティティ | 現行管理方法 | 主要属性 |
|-------------|-------------|---------|
| **工事** | Excel行（工番単位） | 工事番号, 客先名, 工事名, 品種, 納期, 重量, 図面受領日 |
| **品種** | シート分類 | I型, 箱型, 座繰り, SEF, 伸縮装置, 検査路, 排水装置 等 |
| **工程** | 固定6列 | 組立前, 組立, 溶接, 歪取り, 塗装, 仕上げ |
| **製作班** | シート分割 | 中野班, 道姓班, 阪上班, （未割当て） |
| **担当者** | セル入力 | 渡邊, 桝元, 佐藤, チェン, 木下, 中村, 白水, 大庭, 村田 等 |
| **カテゴリ** | 集計行 | 伸縮, 伸縮外, 橋体 |

### 2.2 トランザクションデータ

| エンティティ | 現行管理方法 | 主要属性 |
|-------------|-------------|---------|
| **作業予定** | 工程展開マクロ | 工事 × 期間(1-4) × 着手日 × 完了日 × 比率% |
| **日次配分時間** | カレンダーセル | 工事 × 日付 → 配分時間（時間/日） |
| **日報実績** | 外部xls連携 | 工事 × 日付 → 実績時間 |
| **工程別実績** | 班シート | 工事 × 工程 × 日付 → 実績時間 |
| **過去実績** | 12年蓄積xls | 品種 × 工程 → 平均製作時間 |

## 3. 機能要件

### F1: 工事マスタ管理

| 機能 | 現行 | システム化 |
|------|------|-----------|
| 工事一覧の表示 | Sheet1 行32以降 | 一覧画面（フィルタ・ソート・検索） |
| 工事の追加 | 工事一覧更新マクロ → InputBox | 工事登録フォーム |
| 工事の編集 | セル直接編集 | 編集フォーム |
| 外部データ同期 | 原寸実績.xls から VBA で取込 | CSV/Excel インポート or API連携 |
| 山積み要否の判定 | InputBox（○/x） | 工事登録時のフラグ |

### F2: 工程スケジュール管理（山積み）

| 機能 | 現行 | システム化 |
|------|------|-----------|
| 期間1-4の設定 | セル入力（比率/着手日/完了日） | 工程設定UI（ガントチャート or フォーム） |
| 日次展開 | 展開マクロ（均等配分） | 自動展開API（着手〜完了の稼働日に均等配分） |
| 未工程フラグ | 負の値で表示 | ステータス属性（確定/未確定） |
| 日次配分の確認 | 7,380列のカレンダー | カレンダービュー / ガントチャート |

### F3: 日報実績の反映

| 機能 | 現行 | システム化 |
|------|------|-----------|
| 日報データ取込 | VBAで外部xls読み込み | 班シートの日次カレンダー直接入力 or CSV取込 |
| 実績のカレンダー反映 | マクロで列特定→書き込み | 班シートセル入力 → 自動反映 |
| 進捗率の計算 | 手動/数式 | 実績時間 ÷ 予定時間 で自動計算 |

### F4: 山積みグラフ（負荷チャート）

| 機能 | 現行 | システム化 |
|------|------|-----------|
| カテゴリ別負荷推移 | 名前定義 → Excelグラフ | インタラクティブチャート |
| ペースライン | 定時間/2H残業/4H残業 | キャパシティライン設定 → オーバーレイ表示 |
| グラフ期間の変更 | C2セル変更 → 名前定義再設定 | 日付ピッカー / ズーム |
| 受領状態別の表示 | 受領済み/未受領/未工程の色分け | フィルタ + 色分け凡例 |

### F5: 製作班別工程管理

| 機能 | 現行 | システム化 |
|------|------|-----------|
| 班別の工事一覧 | シート分割 | 班フィルタ付き一覧 |
| 工程別目標配分 | 固定比率（24.9%/16.7%/...） | 設定マスタ（品種別に比率変更可能） |
| 日次実績入力 | セル直接入力 | 班シート（/teams/[id]）の日次カレンダー |
| 目標 vs 実績の差異 | 数式計算 | ダッシュボード自動集計 |
| 班への工事振り分け | シート間でコピー | ドラッグ&ドロップ or セレクト |

### F6: 統合サマリ・KPI

| 機能 | 現行 | システム化 |
|------|------|-----------|
| 全班横断の進捗一覧 | 表シート（INDEX/MATCH） | ダッシュボード |
| 鍛冶/溶接の2系統管理 | W割合の手入力 → 数式 | 溶接比率設定 → 自動分解 |
| 予想完了時間の算出 | 実績÷進捗率×100 | リアルタイム予測表示 |
| 配信用レポート | 配信用グラフシート | PDF/画像エクスポート or ダッシュボード共有 |

### F7: 過去実績マスタ

| 機能 | 現行 | システム化 |
|------|------|-----------|
| 品種別の過去平均時間 | 12年蓄積xls | 過去実績の自動集計 |
| 新規工事の予定時間見積り | 手動参照 | 品種選択 → 推奨予定時間を自動提案 |
| 相関分析 | 箱型の相関係数列 | 統計分析機能（オプション） |

       │

## 5. 画面設計（案）

### 5.1 ダッシュボード（トップ）
- 山積みグラフ（メインチャート）: カテゴリ別負荷 + ペースライン
- KPI カード: 今月の負荷率、遅延工事数、進捗率平均
- フィルタ: 期間、カテゴリ、班、担当者

### 5.2 工事一覧
- テーブルビュー: 工事番号/工事名/品種/納期/重量/班/進捗%/差異
- インライン編集可能
- CSV/Excel インポートボタン

### 5.3 工事詳細
- 基本情報フォーム
- 期間1-4の設定UI（タイムライン or カレンダー）
- 工程別目標 vs 実績のバーチャート
- 日次の配分/実績カレンダー

### 5.4 班別ビュー
- 班ごとの工事一覧 + 日次カレンダー（班シート再現）
- 日次実績入力（工事×工程×日付のセル直接入力。独立した日報入力画面は持たない）
- 班の負荷推移グラフ

### 5.5 設定
- 工程マスタ（比率の編集）
- 品種マスタ
- カレンダー（休日設定）
- キャパシティ設定（定時間/残業のペースライン）
- チーム・担当者管理

## 6. 移行戦略

### Phase 1: 基盤（認証 + マスタ）
- 既存の Firebase 認証 + マルチテナント基盤を流用
- 工程・品種・チーム・カレンダーのマスタ CRUD
- 過去12年データの一括インポート

### Phase 2: 工事管理 + 山積み
- 工事 CRUD + CSV/Excel インポート
- 期間1-4の設定 + 日次展開ロジック
- 山積みグラフ（基本版）

### Phase 3: 日次運用
- 班シートの日次カレンダー直接入力（`/teams/[id]`）
- 進捗率の自動計算
- 班別ビュー + KPI ダッシュボード

### Phase 4: 高度化
- 予想完了時間の算出
- アラート（納期超過リスク、キャパシティ超過）
- レポート出力（配信用グラフ相当）
- 過去実績からの予定時間自動提案

## 7. 技術的な置換対応

| 現行（Excel/VBA） | 新システム |
|-------------------|-----------|
| 7,380列のカレンダー | `DailyAllocation` テーブル（工事×日付） |
| INDEX/MATCH での班→表集計 | SQL JOIN + 集計クエリ |
| VBA `展開` マクロ | API: `POST /projects/:id/expand` |
| VBA `日報反映` マクロ | API: `POST /teams/:id/schedule/cell`（班シート直接入力） |
| VBA `工事一覧更新` マクロ | API: `POST /projects/import` |
| 名前定義 + Excelグラフ | Chart.js / Recharts / ECharts |
| 共有ドライブの外部ファイル参照 | システム内データで完結 |
| セル直接入力 | フォーム入力 + バリデーション |
| シート分割による班管理 | `teamId` によるフィルタリング |
